## SISTEMA BANCÁRIO

Um sistema bancário simples, onde o usuário pode cadastrar clientes e fazer operações com o mesmo. Desenvolvido principalmente para praticar POO em Java.

# TECNOLOGIAS

Java

# FUNCIONALIDADES

Cadastrar clientes
Ativar conta para operações
Depositar
Sacar
Transferir
Consultar saldo
Listar clientes
Sair (finalizar seção)

# COMO USAR

Clone o repositório
Instale uma IDE na sua maquina
Executar o arquivo Main.java
